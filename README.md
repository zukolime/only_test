# Исторические события

Интерактивный блок с краткой информацией об исторических событиях, сгруппированных по различным сферам: **спорт, искусство, литература, технологии, кино и наука**.

Компонент отображает временные периоды на окружности. При переключении периода обновляется временной диапазон и отображается слайдер с ключевыми событиями выбранного интервала.

## Навигация

**Десктопная версия**

- переключение периодов через интерактивные точки на окружности
- навигация с помощью стрелок под кругом

**Мобильная версия**

- переключение с помощью стрелок
- пагинация в виде точек
